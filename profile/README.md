OrielOS is a free and open-source Linux desktop, tuned for gaming and development, that feels familiar from the first boot. It runs on desktop PCs, starting with NVIDIA RTX graphics, and it's built on Fedora with KDE Plasma.

- **Familiar from the first boot.** A centred taskbar, a Start menu with search, the keyboard shortcuts you already know, and Settings organised by task.
- **Tuned for gaming.** Install Steam from the Store and play Windows games through Proton.
- **Updates you can trust.** Whole-system updates apply on restart, and you can go back to the previous version in one click.
- **No telemetry.** OrielOS itself collects nothing.

OrielOS is in early development. [Status](https://orielos.org/guides/status/) lists what works today.
